# Pustaka ornamen SVG Omah Aksara

Aset dekoratif bersama untuk tema undangan. Semua file berbentuk SVG lokal, tidak memerlukan CDN, dan dapat dipakai oleh tema mana pun melalui path repository. Warna, ukuran, dan opacity dapat diatur melalui CSS `filter`, `width`, `height`, atau `mask-image` bila sesuai.

| File | Kegunaan |
|---|---|
| `wayang-gunungan.svg` | Ornamen gunungan/wayang untuk tema Jawa |
| `jendela-jawa.svg` | Bingkai jendela atau gebyok bergaya Jawa |
| `batik-parang.svg` | Pola pengisi, border, atau latar tekstur |
| `floral-divider.svg` | Pemisah bagian bertema floral |
| `arch-islamic.svg` | Lengkung/mihrab dekoratif untuk tema islami |
| `frame-corners.svg` | Aksen sudut bingkai foto/konten |
| `leaf-branch.svg` | Ranting daun untuk tema botanical |
| `jasmine.svg` | Bunga melati untuk aksen pernikahan |
| `ukiran-bali.svg` | Motif ukiran floral Nusantara |
| `geo-islamic.svg` | Geometri islami untuk latar atau medali |

## Pedoman

- Pilih ornamen sesuai karakter tema; jangan menempelkan semua ornamen ke semua tema.
- Gunakan SVG sebagai dekorasi, bukan pengganti teks penting atau kontrol interaktif.
- Pertahankan rasio gambar dan gunakan `aria-hidden="true"` untuk ornamen yang murni dekoratif saat ditanam langsung dalam HTML.
- Aset baru ditambahkan dengan nama file deskriptif, huruf kecil, dan tanda hubung agar konsisten.
