# Atribusi aset tema

## Aset orisinal Omah Aksara
- `frames/jendela-jawa-arch.svg` — bingkai jendela lengkung dekoratif, desain orisinal Omah Aksara.
- `ornaments/gunungan-line.svg` — interpretasi garis dekoratif orisinal terinspirasi bentuk gunungan; bukan replika artefak wayang tradisional.
- `ornaments/floral-corner.svg` — ornamen bunga sudut orisinal Omah Aksara.
- `patterns/kawung-repeat.svg` — motif geometris dekoratif orisinal yang terinspirasi pola kawung; bukan salinan file pihak ketiga.
