# Folder Foto — Rama & Venni

Unggah foto undangan ke folder ini. Gunakan format **JPG/JPEG** dan nama file persis seperti daftar berikut agar langsung terbaca oleh JSON undangan.

## Foto utama
- `foto-sampul.jpg` — foto sampul/cover
- `foto-pria.jpg` — foto Pratu Rama
- `foto-wanita.jpg` — foto Venni

## Galeri (maksimal 20 foto)
- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`
- ...
- `foto20.jpg`

Urutan galeri mengikuti nomor file. Jika foto belum ada, jangan unggah file kosong sebagai pengganti.

## Catatan
- Lokasi folder: `clients/venni-rama/foto/`
- Jangan mengubah atau menghapus `data.json`.
- Foto boleh diunggah bertahap.
- Disarankan gunakan foto asli beresolusi baik; kompresi akan dilakukan tanpa mengubah urutan nama file.
