Setelah selesai
  1. Ekstrak ZIP hasil kompresi.
  2. Periksa nama file agar cocok dengan path foto di data.json.
  3. Unggah semua JPG ke folder klien yang sesuai, misalnya clients/nama-klien/.
  4. Jangan mengubah path foto di JSON jika nama file tetap sama.

Catatan: proses ini tidak mengubah JSON, tema, folder klien, atau foto lama. Beberapa format seperti HEIC mungkin belum dapat dibaca browser; konversikan ke JPG terlebih dahulu jika gagal.
